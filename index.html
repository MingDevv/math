📖 1. นิยามและแนวคิดพื้นฐานเรื่องเซต

สาระการเรียนรู้แกนกลาง

เซต (Set) ในทางคณิตศาสตร์เป็น อนิยาม (Undefined term) ที่หมายถึง การรวมกลุ่มของสิ่งต่าง ๆ โดยมีขอบเขตและเงื่อนไขที่ชัดเจนแน่นอน จนสามารถตัดสินได้เด็ดขาดว่าสิ่งใด อยู่ในกลุ่ม หรือ ไม่อยู่ในกลุ่ม

สิ่งที่อยู่ในเซตเรียกว่า สมาชิก (Element) สัญลักษณ์ที่ใช้แสดงความสัมพันธ์:

∈ เป็นสมาชิกของ

ใช้เมื่อสิ่งนั้นอยู่ในเซต เช่น 2 ∈ {1, 2, 3}

a ∈ A แปลว่า "a เป็นสมาชิกของ A"

∉ ไม่เป็นสมาชิกของ

ใช้เมื่อสิ่งนั้นไม่ได้อยู่ในเซต เช่น 4 ∉ {1, 2, 3}

b ∉ A แปลว่า "b ไม่เป็นสมาชิกของ A"

∅ หรือ { } เซตว่าง

เซตที่ไม่มีสมาชิกเลยแม้แต่ตัวเดียว และมี n(∅) = 0

∅ = { } (ระวัง: {∅} ไม่ใช่เซตว่าง)

U เอกภพสัมพัทธ์

ขอบเขตของสมาชิกทั้งหมดที่เรากำลังพิจารณาในบริบทนั้น

U = {x | x เป็นจำนวนนับ 1–100}

🔢 สัญลักษณ์เซตของจำนวนที่ต้องรู้ใน ม.4

พบบ่อยในข้อสอบ
สัญลักษณ์ ชื่อเรียก ตัวอย่างสมาชิก
ℕ หรือ I⁺ เซตของจำนวนนับ หรือ จำนวนเต็มบวก {1, 2, 3, 4, 5, ...}
ℤ หรือ I เซตของจำนวนเต็มทั้งหมด (บวก, ศูนย์, ลบ) {..., -3, -2, -1, 0, 1, 2, 3, ...}
ℤ⁻ หรือ I⁻ เซตของจำนวนเต็มลบ {-1, -2, -3, -4, ...}
ℚ เซตของจำนวนตรรกยะ (เขียนเป็นเศษส่วน a/b ได้) { 0.5, 3/4, -2, 7, 0.333... }
ℝ เซตของจำนวนจริงทั้งหมด (ตรรกยะ + อตรรกยะ) { -5, 0, 2/3, √2, π, e, 4.8 }

🔄 การเขียนแสดงเซต: แจกแจงสมาชิก vs บอกเงื่อนไข

1. แบบแจกแจงสมาชิก (Roster Form)

เขียนสมาชิกทุกตัวลงในวงเล็บปีกกา { } และคั่นด้วยจุลภาค ถ้ามีมากให้ใช้จุดไข่ปลา (...) เช่น

A = {2, 4, 6, 8, 10}
B = {1, 3, 5, 7, ...}

2. แบบบอกเงื่อนไข (Set-Builder Form)

ใช้ตัวแปรแทนสมาชิก และบอกคุณสมบัติร่วมกัน โดยมีเครื่องหมาย "|" อ่านว่า "โดยที่" เช่น

A = {x | x เป็นจำนวนคู่บวกที่ ≤ 10}
B = {x ∈ ℤ | x² - 4 = 0}

📚 ประเภทของเซต (Classification of Sets)

แนวคิดสำคัญ

1. เซตจำกัด (Finite Set)

เซตที่สามารถระบุจำนวนสมาชิกเป็นจำนวนเต็มบวกใดๆ หรือศูนย์ได้ (นับสมาชิกได้สิ้นสุด)

A = {1, 2, 3, 4, 5} → n(A) = 5

2. เซตอนันต์ (Infinite Set)

เซตที่ไม่ใช่เซตจำกัด มีสมาชิกมากมายนับไม่ถ้วน ไม่สามารถบอกจำนวนสมาชิกได้

B = {x ∈ ℕ | x > 0} = {1, 2, 3, ...}

3. เซตว่าง (Empty Set : ∅)

เซตที่ไม่มีสมาชิกเลย ถือเป็น เซตจำกัด เพราะนับจำนวนสมาชิกได้เท่ากับ 0

C = {x ∈ ℝ | x² + 1 = 0} = ∅

4. เอกภพสัมพัทธ์ (Universal Set : U)

เซตที่บ่งบอกขอบเขตของสมาชิกทั้งหมดที่เราสนใจ สมาชิกทุกตัวต้องอยู่ใน U

U = {x ∈ ℤ | -10 ≤ x ≤ 10}

⚖️ เซตที่เท่ากัน (Equal Sets) vs เซตที่เทียบเท่ากัน (Equivalent Sets)

จุดที่มักสับสนในข้อสอบ

นักเรียนหลายคนมักจำสับสนระหว่าง 2 คำนี้ ซึ่งมีความหมายต่างกันอย่างสิ้นเชิง:

เซตที่เท่ากัน (Equal Sets : A = B)

เซตทั้งสองต้องมี สมาชิกเหมือนกันทุกตัว (หน้าตาเหมือนกันเป๊ะ สลับลำดับได้)

A = {1, 2, 3}, B = {3, 1, 2} → A = B

✓ สมาชิกซ้ำในเซตไม่มีผล เช่น {1, 2, 2} = {1, 2}

เซตที่เทียบเท่ากัน (Equivalent Sets : A ~ B)

เซตทั้งสองมี จำนวนสมาชิกเท่ากัน คือ n(A) = n(B) (สมาชิกไม่จำเป็นต้องเหมือนกัน)

A = {1, 2, 3}, B = {ก, ข, ค} → A ~ B

★ กฎสำคัญ: ถ้า A = B แล้ว A ย่อมเทียบเท่ากับ B เสมอ!

🔍 เครื่องมือตรวจสอบความสัมพันธ์ระหว่างเซต A และ B

🧬 สับเซต (Subset) และ เพาเวอร์เซต (Power Set)

ทฤษฎีบทสำคัญ

สับเซต (A ⊆ B)

A เป็นสับเซตของ B ก็ต่อเมื่อ สมาชิกทุกตัวของ A เป็นสมาชิกของ B

ถ้ามี x ∈ A แม้แต่ตัวเดียวที่ x ∉ B จะถือว่า A ⊄ B

สับเซตแท้ (A ⊂ B)

A เป็นสับเซตของ B และ A ≠ B (ต้องมีสมาชิกของ B อย่างน้อย 1 ตัวที่ไม่อยู่ใน A)

จำนวนสับเซตแท้ = 2ⁿ - 1 เซต

เพาเวอร์เซต P(A)

เซตที่มีสมาชิกคือ สับเซตทั้งหมดของ A นั่นคือ P(A) = { X | X ⊆ A }

n(P(A)) = 2ⁿ เสมอ

กฎเหล็กที่ต้องจำตลอดกาล

1. ∅ ⊆ A เสมอ (เซตว่างเป็นสับเซตของทุกเซต)
2. A ⊆ A เสมอ (ทุกเซตเป็นสับเซตของตัวเอง)
3. ∅ ∈ P(A) และ A ∈ P(A) เสมอ

⚡ เครื่องคำนวณและแจกแจงเพาเวอร์เซต P(A)

💡 เทคนิคการแก้โจทย์ปัญหาเซต (Set Problem Solving)

สูตรหาจำนวนสมาชิก

โจทย์ปัญหาเรื่องเซตใน ม.4 และข้อสอบเข้ามหาวิทยาลัย มักเกี่ยวข้องกับการสำรวจจำนวนคน โดยมีหัวใจสำคัญคือ:

สูตร 2 เซต

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

หรือ n(U) = n(A ∪ B) + n(ไม่เอาทั้งคู่)

สูตร 3 เซต (หลักการบวก-ลบเข้า)

n(A∪B∪C) = n(A)+n(B)+n(C) − n(A∩B) − n(B∩C) − n(C∩A) + n(A∩B∩C)

🧮 โปรแกรมคำนวณและวาดแผนภาพ 2 เซต

คำนวณตามขั้นตอน

กรอกตัวเลขในแต่ละช่อง (ปรับเปลี่ยนได้ตามโจทย์ของคุณ ระบบจะคำนวณผลลัพธ์และวาดแผนภาพเวนน์ให้ทันที)

📝 ตัวอย่างโจทย์สอบเข้ามหาวิทยาลัย (พร้อมเฉลยละเอียด)

โจทย์ตัวอย่าง: การสำรวจนักเรียน 100 คน

ในการสำรวจนักเรียนชั้น ม.4 จำนวน 100 คน พบว่า มีนักเรียนชอบเรียนคณิตศาสตร์ 55 คน ชอบเรียนฟิสิกส์ 40 คน และชอบทั้งสองวิชา 20 คน จงหาว่ามีนักเรียนที่ไม่ชอบเรียนทั้งสองวิชากี่คน?

วิธีทำ:
1. ให้ U คือนักเรียนทั้งหมด → n(U) = 100
2. ให้ M คือชอบคณิต → n(M) = 55, P คือชอบฟิสิกส์ → n(P) = 40, ชอบทั้งสอง → n(M ∩ P) = 20
3. ใช้สูตร: n(M ∪ P) = n(M) + n(P) - n(M ∩ P) = 55 + 40 - 20 = 75 คน
4. นักเรียนที่ไม่ชอบทั้งสองวิชา = n(U) - n(M ∪ P) = 100 - 75 = 25 คน

📜 สรุปสมบัติพีชคณิตของเซต (Algebraic Laws of Sets)

ต้องแม่นยำ
ชื่อกฎ (Law) สมบัติการยูเนียน (∪) สมบัติการอินเตอร์เซกชัน (∩)
กฎการสลับที่ (Commutative) A ∪ B = B ∪ A A ∩ B = B ∩ A
กฎการเปลี่ยนหมู่ (Associative) (A ∪ B) ∪ C = A ∪ (B ∪ C) (A ∩ B) ∩ C = A ∩ (B ∩ C)
กฎการแจกแจง (Distributive) A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C) A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
กฎเอกลักษณ์ (Identity) A ∪ ∅ = A  |  A ∪ U = U A ∩ U = A  |  A ∩ ∅ = ∅
กฎเดอมอร์แกน (De Morgan's) ★ (A ∪ B)′ = A′ ∩ B′ (A ∩ B)′ = A′ ∪ B′
กฎผลต่าง (Difference) ★ A − B = A ∩ B′ = A − (A ∩ B)

⚠️ 5 กับดักข้อสอบยอดฮิต ที่นักเรียนมักเสียคะแนน

กับดักที่ 1: เซตว่างกับปีกกา

∅ ≠ { ∅ } เพราะ ∅ ไม่มีสมาชิก (n=0) แต่ { ∅ } มีสมาชิก 1 ตัว คือเซตว่าง (n=1)

กับดักที่ 2: สับเซตแท้

สับเซตแท้ของ A ห้ามเท่ากับตัวเซต A เอง ดังนั้นจำนวนสับเซตแท้คือ 2ⁿ - 1 (ลบตัวมันเองออก 1)

กับดักที่ 3: สับสนระหว่าง ∈ กับ ⊆

∈ เชื่อมระหว่าง "สมาชิก" กับ "เซต"
⊆ เชื่อมระหว่าง "เซต" กับ "เซต" (เช่น 1 ∈ {1} แต่ {1} ⊆ {1})

กับดักที่ 4: สมาชิกของเพาเวอร์เซต

สมาชิกทุกตัวของ P(A) ต้องเป็นเซตเสมอ ดังนั้น ∅ ∈ P(A) เสมอไม่ว่า A จะเป็นเซตใดก็ตาม

ข้อที่ 1 / 15
คะแนนปัจจุบัน: 0
คู่ที่สำเร็จ: 0 / 10
จำนวนครั้งที่เปิด: 0

คลิกเปิดการ์ด 2 ใบเพื่อจับคู่ระหว่าง สัญลักษณ์/สูตร กับ ความหมาย ที่ถูกต้อง
