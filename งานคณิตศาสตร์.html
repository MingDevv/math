ห้องทดลองเซต

เรียนรู้เรื่องเซตตั้งแต่นิยาม สับเซต เพาเวอร์เซต แผนภาพเวนน์ ไปจนถึงการดำเนินการระหว่างเซต แล้วทดสอบความเข้าใจด้วยเกมท้ายบท

นิยามและสัญลักษณ์

เซต (Set) คือการรวมกลุ่มของสิ่งต่าง ๆ ที่มีขอบเขตแน่นอน ชัดเจนว่าสิ่งใดเป็นสมาชิกและสิ่งใดไม่เป็น สิ่งที่อยู่ในเซตเรียกว่า สมาชิก (element)

เขียนแสดงเซตได้ 2 แบบ:
• แบบแจกแจงสมาชิก เช่น A = {1, 2, 3, 4}
• แบบบอกเงื่อนไข เช่น A = {x | x เป็นจำนวนนับที่น้อยกว่า 5}

สัญลักษณ์ที่ใช้บ่อย: ∈ แปลว่า "เป็นสมาชิกของ", ∉ แปลว่า "ไม่เป็นสมาชิกของ", ∅ แทนเซตว่าง, U แทนเอกภพสัมพัทธ์ (ขอบเขตของสิ่งที่กำลังพูดถึง)

ลองตรวจสอบสมาชิกเอง

การเขียนแสดงเซต: สองแบบที่ต้องแปลงกันได้

แบบแจกแจงสมาชิก (Roster)

A = {2, 4, 6, 8}

เขียนสมาชิกทีละตัวในวงเล็บปีกกา คั่นด้วยจุลภาค

แบบบอกเงื่อนไข (Set-builder)

A = {x | x เป็นจำนวนคู่บวกที่น้อยกว่า 10}

บอกกฎที่สมาชิกทุกตัวต้องเป็นจริง แทนที่จะไล่เขียนทีละตัว

ตัวอย่างเซตอนันต์แบบ Roster

B = {5, 10, 15, 20, ...}

ใช้จุดไข่ปลาแทนรูปแบบที่ดำเนินต่อไปเรื่อย ๆ

แปลงกลับกัน

{1,3,5,7,9} ↔ {x | x คือเลขคี่ 1–9}

สองแบบนี้แทนเซตเดียวกัน เลือกใช้แบบไหนก็ได้ตามความสะดวก

ประเภทของเซต

เซตจำกัด (Finite Set)

เซตที่นับจำนวนสมาชิกได้ครบถ้วน

A = {1, 2, 3, 4}

เซตอนันต์ (Infinite Set)

เซตที่มีสมาชิกไม่สิ้นสุด นับไม่ครบ

B = {1, 2, 3, 4, ...}

เซตว่าง (Empty Set)

เซตที่ไม่มีสมาชิกเลย เขียนแทนด้วย ∅ หรือ { }

C = {x | x เป็นคนที่สูงเกิน 5 เมตร} = ∅

เอกภพสัมพัทธ์ (Universal Set)

เซตที่กำหนดขอบเขตของสิ่งที่กำลังพิจารณาทั้งหมด

U = {1, 2, 3, ..., 10}

สับเซต (Subset)

A เป็นสับเซตของ B เขียนแทนด้วย A ⊆ B หมายความว่า สมาชิกทุกตัวของ A ต้องเป็นสมาชิกของ B ด้วย เซตว่าง (∅) และตัวเซตเอง เป็นสับเซตของทุกเซตเสมอ

เพาเวอร์เซต (Power Set)

เพาเวอร์เซตของ A คือเซตที่มีสมาชิกเป็นสับเซตทั้งหมดของ A ถ้า A มีสมาชิก n ตัว จำนวนสับเซตทั้งหมดจะเท่ากับ 2ⁿ ตัว

ลองสร้างสับเซตและเพาเวอร์เซตเอง

มุมมอง 3 มิติ: เพาเวอร์เซตเป็นลูกบาศก์

แต่ละมุมของลูกบาศก์คือหนึ่งสับเซต เส้นเชื่อมแสดงการเพิ่ม/ลดสมาชิกทีละตัว — ลากหมุนดูได้

กำหนดเซต

การดำเนินการ

ลากเมาส์ (หรือปัดนิ้วบนมือถือ) เพื่อหมุนดูรอบทิศทาง — ทรงกลมที่จางลงคือส่วนที่ไม่ได้อยู่ในคำตอบ

สมบัติของการดำเนินการเซต

A ∪ B = B ∪ A และ A ∩ B = B ∩ A (สลับที่ได้)  •  (A ∪ B) ∪ C = A ∪ (B ∪ C) (เปลี่ยนหมู่ได้)  •  กฎเดอมอร์แกน: (A ∪ B)′ = A′ ∩ B′ และ (A ∩ B)′ = A′ ∪ B′

การแก้ปัญหาโดยใช้เซต

โจทย์ปัญหาที่พูดถึงคนหรือสิ่งของสองกลุ่มที่มีส่วนซ้อนกัน มักแก้ได้ง่ายที่สุดด้วยการ "เติมตัวเลขลงในแผนภาพเวนน์" โดยเริ่มเติมจากส่วนที่ซ้อนกัน (ทั้งสองอย่าง) ก่อนเสมอ แล้วค่อยหักลบหาส่วนที่เหลือ ใช้สูตรหลัก:

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

ลองแก้โจทย์ด้วยตัวเอง

ตัวอย่าง: ในห้องเรียนมีคนชอบฟุตบอลอย่างเดียว 11 คน ชอบบาสอย่างเดียว 6 คน ชอบทั้งสองอย่าง 4 คน — ปรับตัวเลขเป็นโจทย์ของตัวเองได้เลย
